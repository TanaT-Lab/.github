# TanaT Lab

**TanaT Lab** develops methodologies and open-source tools for trajectory analysis, longitudinal data modeling, and Deep Learning applications, with a specialized focus on patient care pathways.

### Main project

| Repository | Description | 
|---|---|
| [TanaT](https://github.com/TanaT-Lab/TanaT) | Core library for trajectory analysis |
| [tanat-synthea](https://github.com/TanaT-Lab/tanat-synthea) | Synthetic patient journey datasets for longitudinal analysis | 
| [tanat-embs](https://github.com/TanaT-Lab/tanat-embs) | WIP - Experiments and implementation of Embeddings facilities | 
| [tanat-utils](https://github.com/TanaT-Lab/tanat-utils) | Shared utilities for the TanaT ecosystem |

---
*Open source software designed to advance trajectory analysis in research and industry applications.*
